### Basic exercise

Create a box with the following properties:

- `100px` wide
- `50px` high
- contains red text
- `3px` padding
- `1px` solid border with colour `#333333`
- `5px` of margin on the left and right, and `10px` of margin on the top and bottom
- background colour of `rgb(255,255,0)`
